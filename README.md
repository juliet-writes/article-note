# 기사 프로젝트 노트

기사 프로젝트 진행 상황을 한 페이지에 정리하는 노트입니다. HTML 파일 하나로 되어 있고, 별도 설치나 서버 없이 브라우저에서 바로 열립니다. 휴대폰 화면에서도 보기 편하게 만들었습니다.

작성자: [juliet-writes](https://github.com/juliet-writes)

## 구성

| 칸 | 내용 |
|---|---|
| 프로젝트 한 줄 | 프로젝트 브리프를 한 줄로 |
| 팀 이름과 역할 | 팀 이름과 내 역할 |
| 주제 | 배정받은 대주제 (내 앵글은 별도로 정함) |
| 할 일 체크리스트 | 5개 항목, 체크 가능 |
| 날짜별 기록 | 날짜별로 한 줄씩, 11/18부터 시작, 날짜 추가 가능 |

## 사용법

1. `project-note.html` 파일을 브라우저로 엽니다.
2. 각 칸을 눌러 바로 입력합니다.
3. 입력한 내용과 체크 상태는 사용 중인 브라우저에 자동 저장됩니다.

## 참고

- 저장은 브라우저의 로컬 저장소에만 되며, 서버로 전송되지 않습니다. 다른 기기나 다른 브라우저에서는 내용이 보이지 않습니다.
- 브라우저 데이터를 지우면 입력한 내용도 함께 사라집니다. 중요한 내용은 따로 백업해 두세요.
- 전화번호, 주소 같은 개인정보 칸은 만들지 않았습니다.
- 저장소를 공개(public)로 올릴 경우 HTML 파일에는 입력 내용이 들어 있지 않고 빈 양식만 올라갑니다.
